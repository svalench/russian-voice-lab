# Qwen3 1.7B вместо 4B — 25 октября 2026

Основной режим приложения переключён на **Qwen3 1.7B 4-bit + Piper / Ирина**. ASR остался Qwen3-ASR 0.6B. Обработка полностью локальная; веса скачаны в `.models/llm-small/`. Прежние 4B-веса в `.models/llm/` сохранены.

В шаблоне Qwen3 явно задано `enable_thinking=False`. Проверено на настоящем токенизаторе: запрос закрывает блок рассуждений до начала генерации. В десяти ответах блоков `<think>` не было. Описание переключения режима — в [карточке Qwen3 1.7B](https://huggingface.co/Qwen/Qwen3-1.7B).

## Сравнение на этом Mac

Последовательно проверены обе модели: по 10 одинаковых русских аудиофайлов, тот же ASR, голос и инструкция. Для 1.7B повторно использованы WAV из прогона 4B; тексты распознавания совпали во всех 10 случаях. Исходящие Python-соединения во время запуска моделей заблокированы. Первый ход исключён из медиан, память учитывает весь прогон.

| Метрика | 4B | 1.7B |
| --- | ---: | ---: |
| Медиана первого токена LLM | 0,98 с | 0,38 с |
| Медиана готовности первого аудио | 4,43 с | 1,71 с |
| Медиана распознавания речи | 1,21 с | 0,67 с |
| Пик выделений MLX | 3,43 ГБ | 2,21 ГБ |
| Размер файла весов LLM | 2263 МБ | 968 МБ |

В этой серии серверная готовность первого аудио ускорилась примерно в 2,6 раза. Это измерение после окончания реплики, без паузы VAD: в обычном разговоре добавляется примерно 700 мс и задержка аудиоустройства. Компьютер работал с энергосбережением и фоновой нагрузкой. ASR тоже выполнился быстрее, поэтому всё улучшение нельзя приписать только размеру LLM. Замеры ориентировочные, гарантии постоянного времени ответа нет.

Браузерный тест с настоящими моделями и синтетическим аудиовходом: первый ответ в новом сеансе — **3,86 с с VAD**, перебивание — **186 мс**. Обработаны две реплики, ошибок JavaScript и внешних запросов нет. Живой микрофон пользователя в автоматических проверках не записывался.

## Качество русского диалога

1.7B отвечает на русском, помнит имя «Валентин» и связывает уточнение про город с предыдущим вопросом о Минске. Но качество заметно слабее 4B:

- На правильно распознанное «25 плюс 17» модель 1.7B ответила «38», версия 4B — «42».
- На просьбу посоветовать занятие 1.7B повторила искажённый ASR-запрос, тогда как 4B предложила варианты.
- Встречались неестественные формулировки вроде «Зовутся Валентин» и малоинформативный ответ «Что-то вроде сухого» на вопрос о прогулке под дождём.

Этот профиль оставлен для проверки скорости живого разговора. Если важнее содержательность ответа, можно вернуться к 4B, сохранив тот же русский голос.

## Запуск и откат

```sh
# Меньшая модель и Piper — теперь по умолчанию:
./scripts/run.sh

# Прежняя 4B с тем же голосом:
VOICE_LAB_LLM=4b ./scripts/run.sh
```

Перед переключением остановите предыдущий сервер. Страницу браузера после перезапуска нужно обновить. Текущий размер модели показывается над диалогом.

В новом окружении `./scripts/setup.sh` готовит 1.7B и Piper. Для подготовки старой LLM: `VOICE_LAB_LLM=4b ./scripts/setup.sh`. Веса двух моделей не перезаписывают друг друга.
